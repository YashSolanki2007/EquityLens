DORMANT WEBSITE FEATURES
Last updated: 10 August 2026

Purpose
-------
This inventory records implemented features that are intentionally unavailable on
the website. Check this file before building a similar feature from scratch.

Availability control
--------------------
File: apps/web/lib/feature-availability.ts

The website navigation and route guards use the switches in that file. To restore
a feature, set its switch to true, run the web checks, and update this inventory.
